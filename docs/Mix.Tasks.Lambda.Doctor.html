    mix lambda.doctor (Mayfly v1.0.0-rc.1)

    Copy Markdown View Source

    Runs a set of checks that catch the common setup mistakes before you deploy:

    • a release with the Mayfly.Release steps and a mayfly: [handler: ...] option exists;

    • the configured handler resolves (module implements Mayfly.Handler, or a legacy Module.function exists) and its init/1 succeeds;

    • for layer: true releases, the local ERTS version matches the layer you intend to use (--layer ARN queries Lambda for the layer's OTP version; without it the expected version is printed for you to compare);

    • the Elixir/OTP versions are supported.

      mix lambda.doctor mix lambda.doctor --release lambda --layer arn:aws:lambda:eu-central-1:123:layer:mayfly-erlang-27-arm64:1

    Exit status is 1 when any check fails.
