    Mayfly.Telemetry (Mayfly v1.0.0-rc.1)

    Copy Markdown View Source

    Telemetry events emitted by the runtime. :telemetry is an optional dependency; when it is not present the calls are no-ops.

    EventMeasurementsMetadata
    [:mayfly, :init, :stop]duration (native)handler, result (:ok / :error)
    [:mayfly, :invocation, :start]system_timecontext
    [:mayfly, :invocation, :stop]durationcontext, result (:ok / :error), error_type
    [:mayfly, :poll, :error]backoff_msreason

    Attach with :telemetry.attach/4 from your handler's init/1, or use a reporter such as telemetry_metrics_cloudwatch.
