    Modules

    Mayfly

    Mayfly – an AWS Lambda custom runtime for Elixir.

    Mayfly.Boot

    Entry point used by the generated bootstrap script

    Mayfly.Context

    Per-invocation metadata, built from the GET /runtime/invocation/next response headers and passed as the second argument to Mayfly.Handler.handle/3.

    Mayfly.ErrorPayload

    Builds the error document Lambda expects on /runtime/invocation/<id>/error and /runtime/init/error

    Mayfly.Events

    Typed decoders for the event shapes AWS services send to Lambda.

    Mayfly.Events.DynamoDB

    Amazon DynamoDB Streams events.

    Mayfly.Events.DynamoDB.Record

    One stream record.

    Mayfly.Events.EventBridge

    Amazon EventBridge events (custom events, scheduled rules, AWS service events).

    Mayfly.Events.HTTP

    HTTP events from API Gateway (REST v1 and HTTP v2), Lambda Function URLs (v2 shape) and Application Load Balancer, plus helpers that build the proxy response each of them expects.

    Mayfly.Events.HTTP.Request

    A decoded HTTP request. See Mayfly.Events.HTTP.

    Mayfly.Events.Kinesis

    Amazon Kinesis Data Streams events.

    Mayfly.Events.Kinesis.Record

    One Kinesis record.

    Mayfly.Events.S3

    Amazon S3 event notifications.

    Mayfly.Events.S3.Record

    One S3 notification record.

    Mayfly.Events.SNS

    Amazon SNS notifications delivered directly to Lambda.

    Mayfly.Events.SNS.Record

    One SNS notification.

    Mayfly.Events.SQS

    Amazon SQS events.

    Mayfly.Events.SQS.Record

    One SQS message.

    Mayfly.HTTP

    Minimal HTTP/1.1 client over :gen_tcp for the link-local Lambda Runtime API.

    Mayfly.Handler

    Behaviour for Lambda function handlers.

    Mayfly.LocalRuntime

    A small Lambda Runtime API emulator for local development and tests.

    Mayfly.LogFormatter

    Logger formatter that emits one JSON object per line in the shape Lambda's advanced logging controls expect, so CloudWatch parses level, request id and tenant id

    Mayfly.Metrics

    CloudWatch metrics without API calls, using the Embedded Metric Format: one JSON line on stdout that CloudWatch Logs turns into metrics.

    Mayfly.Poller

    One poller owns one concurrency slot: it long-polls /runtime/invocation/next, runs the handler and posts the result, then polls again.

    Mayfly.Release

    Turns mix release into a Lambda package builder.

    Mayfly.Response

    What a handler may return inside {:ok, _}.

    Mayfly.RuntimeAPI

    Client for the Lambda Runtime API (version 2018-06-01), built on Mayfly.HTTP.

    Mayfly.Supervisor

    Starts one Mayfly.Poller per concurrency slot after the handler has been resolved and initialised exactly once.

    Mayfly.Telemetry

    Telemetry events emitted by the runtime. :telemetry is an optional dependency; when it is not present the calls are no-ops.

    Mix Tasks

    mix lambda.doctor

    Runs a set of checks that catch the common setup mistakes before you deploy

    mix lambda.build

    Builds the Lambda package for a release configured with Mayfly.Release and copies the resulting lambda.zip to --outdir.

    mix lambda.invoke

    Runs your handler exactly as Mayfly would inside Lambda – handler resolution, init/1, JSON decoding, context, error formatting – against Mayfly.LocalRuntime, and prints the response or error.
