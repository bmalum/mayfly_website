# AGENTS.md – elixir-aws-lambda.dev

Static site for Mayfly (Elixir on AWS Lambda). Hosted on Cloudflare Pages,
deployed on every push to `main`. Companion repo: `bmalum/mayfly` (its
`AGENTS.md` and `skills/mayfly-maintainer/` cover the library and the layer
pipeline).

## Build

```bash
npm install
npm run build        # -> dist/  (rm -rf dist; layers.js; tailwind; copy src; copy docs; sitemap.js)
```

Preview: `cd dist && python3 -m http.server 8765` then open
http://localhost:8765/. Do not open `dist/index.html` via `file://`; asset
paths are absolute.

## What lives where

| Path | Purpose | Edit? |
|---|---|---|
| `src/index.html` | landing page (Tailwind utility classes, highlight.js for code) | yes |
| `src/input.css` | Tailwind entry + font-face + code theme; `pre code.hljs` is scoped to the landing page | yes |
| `src/_redirects`, `src/_headers` | Cloudflare Pages config. **Never add `/docs/... → index.html` rewrites**: Pages serves directory indexes and strips `.html` itself; such rules loop | carefully |
| `src/robots.txt`, `src/llms.txt` | crawler / agent entry points | yes |
| `layers.js` | generates `dist/layers/` (catalog page + JSON resolver) from `data/layers.json` | yes |
| `data/layers.json`, `data/layers.updated` | **written by the mayfly `Layers` workflow** (bot commits as `mayfly-layers-bot`). Do not hand-edit; re-run the workflow instead | no |
| `sitemap.js` | generates `dist/sitemap.xml` from `docs/*.html` + fixed pages | yes |
| `docs/` | **generated by ExDoc** from the mayfly repo: `mix docs -o ../mayfly_website/docs`. Never edit by hand; edit `guides/*.md` / moduledocs in mayfly and regenerate | no |
| `docs/dist/` | ExDoc assets (css/js/fonts). Must stay committed; `.gitignore` has `/dist/` (anchored) for that reason | no |

## Conventions

- Internal doc links are extension-less: `/docs/streaming`, `/docs/` (Pages
  redirects `.html` → pretty URL with a 307; avoid the extra hop).
- SEO lives in the `<head>` of `src/index.html` (single H1, meta description,
  Open Graph, JSON-LD graph with WebSite/Organization/SoftwareApplication/
  HowTo/FAQPage/BreadcrumbList). Keep the FAQ `<details>` markup and the
  FAQPage JSON in sync when adding a question.
- Backlinks to https://karrer.solutions (author) stay in hero credit, footer
  and structured data.
- Numbers on the page (cold start, warm latency, zip size) come from real
  measurements; if you change them, state the conditions in the small print.
- Colours: violet `#5B21B6`/`#7C3AED` primary, zinc text, white cards. No dark
  mode.

## Deploy / verify

Push to `main`. Then:

```bash
curl -sI https://elixir-aws-lambda.dev/ | head -1                     # 200
curl -sI https://elixir-aws-lambda.dev/docs/ | head -1                # 200 (not 307/loop)
curl -s  https://elixir-aws-lambda.dev/layers/27/arm64/eu-central-1.json   # JSON
curl -s  https://elixir-aws-lambda.dev/sitemap.xml | grep -c "<loc>"
```

## Regenerating docs after a mayfly change

```bash
cd ../mayfly && mix docs -o ../mayfly_website/docs
cd ../mayfly_website && npm run build && git add -A docs && git commit -m "docs: regenerate for <version>" && git push
```
